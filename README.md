# Patat’outils — Android

Version de test Android de Patat’outils.

## V1 test
- Journal recettes / dépenses local
- Brouillon de facture et calcul TVA / TTC
- Calcul d’irrigation
- Estimation du nombre de plants
- Calcul de rendement
- Poste ferme / caméra locale

Les données restent sur l’appareil. Cette version de test n’est ni une caisse certifiée, ni une plateforme de facturation électronique, ni un logiciel comptable certifié.

Le dépôt distribue uniquement le binaire de test ; le code source n’est pas publié ici.
